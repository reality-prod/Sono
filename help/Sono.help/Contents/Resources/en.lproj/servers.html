Connecting to Servers

Sono communicates with Subsonic and OpenSubsonic API servers to stream your music collection.

← Back to Overview Playback Lyrics Offline Library

Server Requirements

Sono requires a running server with Subsonic API support. Recommended servers include:

  • Navidrome (recommended for native LRC streaming and OpenSubsonic extensions)
  • Gonic
  • LMS (Lightweight Music Server)
  • Airsonic-Advanced
  • Subsonic

Server Address Format

Your server URL should point to your server's root address. Sono automatically handles API subpaths.

  • Local Mac installation: http://localhost:4533
  • Home Network / NAS: http://192.168.1.100:4533
  • Domain with HTTPS: https://music.example.com

Authentication & Security

Sono uses Subsonic token authentication with salt (MD5 hash). Your raw password is encrypted safely in your macOS Keychain and is never sent across the network in plain text.

Troubleshooting Connections

1. "Cannot connect to server" / Connection Refused

  • Verify that your Navidrome server container or service is currently running.
  • Make sure you included the correct port number (default is 4533 for Navidrome).
  • Check if your Mac's firewall or VPN is blocking access to local network IP addresses.

2. "Wrong username or password" (Subsonic Error 40)

  • Check your login credentials in the Navidrome Web UI first to ensure your user account is active.
  • Passwords are case-sensitive. Ensure Caps Lock is off.

3. Reverse Proxy & SSL Issues

  • If you use Nginx, Caddy, or Cloudflare, ensure your reverse proxy forwards WebSocket and REST traffic under /rest/*.
  • Ensure your SSL certificate is valid and recognized by macOS.
